# One Frank

Mini Frank is an independent peer project. It may share the existing Hermes
profile and explicitly project-scoped capabilities, but it must not create a
second Frank or Hermes, merge private project memory, or duplicate a private
state pool. A separate Mini surface must preserve these boundaries rather than
be treated as a second Frank.
