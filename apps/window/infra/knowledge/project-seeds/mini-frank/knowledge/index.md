# Mini Frank core knowledge

The shared core is layered and evidence-led:

- `governance/` — One Frank, Hermes ownership, privacy, and promotion rules.
- `layers/l0-craft/` — durable research, release, reuse, and safety practices.
- `layers/l1-platform/` — current Frank/Hermes platform boundaries.
- `layers/l2-pattern/` — reusable problem structures.
- `layers/l3-vertical/` — narrow, sourced vertical packs.
- `intersections/` — findings created by combining layers.
- `build/` — architectures, repositories, stacks, and UI patterns.

Every approved record identifies exact sources and a refresh date. Candidate
records may be retrieved for consideration but cannot be treated as approved.
Private client context never enters this tree.
