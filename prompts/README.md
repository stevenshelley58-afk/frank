# Prompts

The prompt gallery — every reusable prompt Frank leans on, browsable in the
Frank Console **Files** module.

Suggested groupings (add folders as needed):

```
prompts/
  system/        # central-Frank and mini-Frank system prompts
  rooms/         # per-room identity / orchestration prompts
  templates/     # reusable prompt templates with {{placeholders}}
```

Each file is plain markdown or text. The Console renders markdown and
syntax-highlights everything else.
